# Tianyun Zhong — Academic Homepage

A dependency-free, single-page academic website for GitHub Pages. The site is designed for the repository `tianyumyum.github.io`, which GitHub publishes at `https://tianyumyum.github.io`.

## Contents

- `index.html` — page structure and content
- `assets/papermod.css` — responsive, PaperMod-inspired styling
- `assets/CV_TianyunZhong.pdf` — downloadable CV
- `assets/tianyun-zhong.jpg` — homepage portrait

## Deploy to GitHub Pages

1. Create a public GitHub repository named exactly `tianyumyum.github.io` under the `tianyumyum` account.
2. Upload the contents of this folder to the repository root (not the enclosing folder itself).
3. Commit and push to the `main` branch.
4. In GitHub, open **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/(root)`.
5. After GitHub finishes building, visit `https://tianyumyum.github.io`.

No build command is required. Edit `index.html` to update text and `assets/papermod.css` to adjust presentation.

## Links and source fidelity

The research information and outgoing links were transcribed from `CV_TianyunZhong.pdf`, except for the Google Scholar profile URL supplied by the site owner.
